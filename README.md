# 🤖 Spring GenAI Learning Project – Spring AI + OpenAI

This repository is part of my learning journey into **Spring GenAI (Spring AI)** — exploring how to integrate Generative AI capabilities into Java & Spring Boot applications.

The goal of this project is to understand how GenAI fits into backend systems: prompts, models, context, memory, and tool usage.

- Integrating LLMs with Spring Boot
- Prompt engineering in backend apps
- Using ChatClient and other Spring AI abstractions
- Managing AI configuration securely
- Building AI-powered REST APIs
